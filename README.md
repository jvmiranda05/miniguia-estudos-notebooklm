# 📚 Caderno Temático: Engenharia de Prompt

## 📖 Contexto

Este projeto foi desenvolvido como parte do desafio da DIO utilizando o NotebookLM como ferramenta de aprendizagem ativa.

O tema escolhido foi **Engenharia de Prompt**, uma área importante para melhorar a interação com modelos de Inteligência Artificial Generativa.

Durante o desenvolvimento, foram realizadas pesquisas, testes de prompts e organização dos conhecimentos adquiridos para criar um material de estudo.

## 🎯 Objetivos

- Compreender os fundamentos da Engenharia de Prompt.
- Aprender técnicas para criar prompts mais eficientes.
- Explorar formas de melhorar respostas geradas por Inteligência Artificial.
- Utilizar o NotebookLM como ferramenta de apoio aos estudos.
- Criar um miniguia de consulta para futuras revisões.

# 💡 Engenharia de Prompts e Cicatrizes

Durante o desenvolvimento deste caderno temático, foram realizados testes com diferentes prompts no NotebookLM para compreender como a formulação das perguntas influencia a qualidade das respostas.

## 🧪 Teste de Prompt 1

### Prompt inicial:

"Explique o que é Engenharia de Prompt."

### Resultado obtido:

A resposta apresentou uma explicação geral sobre o tema, porém com poucos exemplos práticos.

### Aprendizado:

Percebi que perguntas muito amplas geram respostas mais genéricas.

---

## 🧪 Teste de Prompt 2

### Prompt aprimorado:

"Explique Engenharia de Prompt para uma pessoa iniciante, utilizando exemplos práticos do cotidiano e mostrando sua importância no uso de Inteligência Artificial."

### Resultado obtido:

A resposta apresentou conceitos mais claros, exemplos e uma estrutura melhor organizada.

### Aprendizado:

Adicionar contexto e definir o público-alvo melhora a qualidade da resposta.

---

## 🧪 Teste de Prompt 3

### Prompt:

"Crie um resumo dos principais conceitos de Engenharia de Prompt presentes nas fontes enviadas, organizando em tópicos e incluindo exemplos."

### Resultado obtido:

Foi gerado um resumo estruturado contendo conceitos como:

- Clareza do prompt;
- Contexto;
- Objetivo da pergunta;
- Exemplos;
- Refinamento das respostas.

### Aprendizado:

Solicitar formatos específicos ajuda a obter respostas mais úteis.

---

# ⚠️ Dificuldades encontradas (Troubleshooting)

Durante os testes, algumas dificuldades foram identificadas:

- Algumas respostas iniciais eram muito genéricas.
- Foi necessário adicionar mais contexto aos prompts.
- Perguntas muito abertas dificultavam a obtenção de informações específicas.
- A melhoria dos prompts aumentou a precisão e relevância das respostas.

---

# 📌 Estratégias que funcionaram melhor

- Informar claramente o objetivo da pergunta.
- Definir o nível de conhecimento esperado.
- Solicitar formatos específicos (listas, tabelas ou resumos).
- Pedir exemplos práticos.
